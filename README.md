# amerged website

Next.js (App Router) landing page for [amerged](https://amerged.com) — Agents Merged into your business.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

Content and design are ported from the editorial single-file HTML landing page. Interactive behaviour lives in `app/amerged-experience.ts` and mounts via the client `Experience` component.
